# IN6227 Assignment 1 – Decision Tree and Random Forest for Mixed-Type Binary Classification

This repository contains the source code, results, figures for IN6227 Assignment 1 (Variant 1). by **Lu Jingxuan (G2603717A)**.

## Files

- `IN6227_Assignment1.ipynb`  
  Main Jupyter Notebook containing data exploration, preprocessing, model training, hyperparameter tuning, and evaluation.

- `dataset/`  
  Contains the training and test datasets used in the assignment.

- `results.json`  
  Stores the selected hyperparameters and final evaluation results for Decision Tree and Random Forest.

- `requirements.txt`  
  Lists the Python packages required to run the notebook.

- `figures/`  
  Contains figures generated during exploratory data analysis and model evaluation.
  

## Run

Install the required packages:

```bash
pip install -r requirements.txt
```
